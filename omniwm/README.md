# OmniWM (macOS)

Linked to `~/.config/omniwm` by `install-mac.conf.yaml`; installed by the `omniwm` cask in `homebrew/Brewfile`.

`settings.toml` is not hand-written. OmniWM's schema is strict — every required table and key must be present, and one unknown hotkey id or missing key rejects the whole file — so the file is generated by OmniWM itself (status-bar menu → "Reveal Settings File") and then edited.

OmniWM's Settings window writes back to `settings.toml`, so changes made in the GUI show up as a diff here.
